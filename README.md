# ⚡ ToolMatrix AI — All-in-One AI Tools Directory & Comparison Engine

An independent, real-time AI tools discovery and side-by-side comparison engine. Compare 40+ industry-leading generative AI models and tools across pricing tiers, free quotas, commercial rights, latency, and technical specifications.

---

## 🌟 Key Features

* **⚡ 4-Way Side-by-Side Comparison Matrix (VS Mode):**
  Compare up to 4 AI tools at once (*e.g., Runway Gen-3 vs Luma Dream Machine vs Kling AI vs Sora*) across 9 crucial dimensions.
* **🎯 8 Curated Categories:**
  - 🎬 **Text to Video** (Runway, Luma, Kling, Hailuo, Pika, Sora)
  - 🎞️ **Image to Video & Motion** (Viggle AI, HeyGen)
  - 🎨 **Text to Image & Design** (Midjourney, FLUX.1, SD 3.5, Ideogram 2.0, DALL-E 3, Recraft)
  - 🧠 **AI Models & LLMs** (GPT-4o, Claude 3.5 Sonnet, Gemini 1.5/2.0, DeepSeek R1/V3)
  - ⚖️ **Legal & Contract AI** (Harvey AI, CoCounsel, Spellbook, Robin AI, DoNotPay)
  - 🎙️ **Voice Cloning & Music AI** (ElevenLabs, Suno AI, Udio)
  - 💻 **Coding & Autonomous Dev Agents** (Cursor, Copilot, Bolt.new)
  - ⚡ **Productivity & Research** (Perplexity AI)
* **💰 Real-Time Pricing Breakdown:**
  Filter instantly by **🟢 100% Free / Open Source**, **🟡 Freemium (Daily Free Quotas)**, or **🟣 Paid Enterprise**.
* **🛡️ Commercial Rights Transparency:**
  Know upfront whether generated videos, images, or audio can legally be used in commercial advertising and client projects.
* **📬 Submit a Tool Workflow:**
  Built-in creator portal allowing developers to submit their AI apps directly to the catalog.
* **🎨 Modern AI-Native Dark UI:**
  Built using guidelines from the **UI/UX Pro Max** design system with responsive layouts, accessible contrast, and smooth micro-interactions.

## 🚀 Quick Start (Local Setup)

```bash
# 1. Clone the repository
git clone https://github.com/SHIVA-TIWARI2403/ai-tool-matrix.git

# 2. Navigate to project folder
cd ai-tool-matrix

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the matrix.
